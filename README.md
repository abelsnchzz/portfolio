# Portfolio de Abel Sánchez Ramos

Portfolio personal orientado a Administrador de Sistemas Junior, Soporte IT y Ciberseguridad.

## Estructura

- `index.html` — contenido de la web.
- `css/style.css` — diseño y responsive.
- `js/script.js` — menú móvil y animaciones.
- `assets/` — imágenes, CV y otros recursos.

## Publicarlo con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todos los archivos manteniendo la estructura de carpetas.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona `Deploy from a branch`.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique la página.

Antes de publicarlo, sustituye los enlaces `#` de LinkedIn y GitHub por tus URLs reales.
