Laboratorio de Infraestructura & IAM

Despliegue de Directorio Activo Seguro con GPOs de Hardening y Microsoft Entra ID

Arquitectura Híbrida

Problema / Objetivo

Implementar una infraestructura de dominio empresarial segura desde cero sobre Windows Server 2022, integrando sincronización híbrida hacia la nube y aplicando directivas restrictivas para mitigar movimientos laterales y ejecuciones no autorizadas.

Implementación Técnica Paso a Paso

  • 01. Instalación y configuración del rol AD DS y DNS Server con estructura jerárquica de Unidades Organizativas (OUs) divididas por departamentos y niveles de privilegio.
  • 02. Despliegue de directivas de grupo (GPOs) para bastionado: deshabilitación de protocolos obsoletos (SMBv1, LLMNR), bloqueo de macros no firmadas y restricción de software mediante AppLocker.
  • 03. Integración de Microsoft Entra Connect para sincronización de identidades hacia Microsoft 365, configurando autenticación multifactor (MFA) obligatoria y políticas de acceso condicional.

Resultados & Validación

Reducción de la superficie de ataque del puesto. Auditoría exitosa de directivas validada con gpresult /v y bloqueo verificado de ejecuciones no permitidas en clientes Windows 10/11.

Tecnologías & Entorno
Windows Server 2022 Active Directory GPOs / Hardening Microsoft Entra ID VMware / VirtualBox

  • ✓ Auditoría de permisos NTFS / Compartidos

Laboratorio SOC & Seguridad Defensiva

Entorno de Detección de Amenazas con SIEM (Wazuh & Splunk) y Simulación de Incidentes

SOC Tier 1 Lab

Problema / Objetivo

Diseñar una plataforma de monitorización y correlación de eventos centralizada para detectar en tiempo real intentos de intrusión, fuerza bruta y modificaciones no autorizadas en servidores críticos.

Implementación Técnica Paso a Paso

  • 01. Despliegue de Wazuh Server & Dashboard sobre Ubuntu Server y configuración de agentes en clientes Windows 10 y servidores Debian.
  • 02. Configuración de módulos FIM (File Integrity Monitoring) para alertar sobre modificaciones en ficheros críticos (/etc/passwd, System32) y módulo de detección de vulnerabilidades CVE.
  • 03. Simulación de ataques con Kali Linux (fuerza bruta SSH con Hydra y escaneos Nmap), analizando la respuesta del SIEM y configurando reglas de detección personalizadas.

Resultados & Validación

Generación de paneles interactivos de seguridad (mapeo MITRE ATT&CK), alertas automáticas por correo y respuesta activa bloqueando IPs atacantes mediante iptables.

Automatización & Análisis

Suite de Scripts en Python y Consultas SQL para Auditoría de Registros IT

SysAdmin Tooling

Problema / Objetivo

Automatizar la detección de anomalías en inicios de sesión y tareas de mantenimiento preventivo de servidores, optimizando la revisión de ficheros de registro dispersos.

Implementación Técnica Paso a Paso

  • 01. Desarrollo de scripts en Python para analizar logs de autenticación (Auth.log y Event Viewer), extrayendo IPs sospechosas y patrones de intentos fallidos.

  • 03. Script en Bash programado en tareas Cron para la verificación automática del almacenamiento, comprobación de servicios y rotación de copias de seguridad.

Resultados & Validación

Reducción significativa del tiempo de revisión rutinaria de logs y generación automática de reportes para auditorías técnicas.
