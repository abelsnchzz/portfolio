Identidad & Directorio Activo
Windows Server 2022 Entra ID Connect GPO Hardening

Laboratorio de Identidad Híbrida Corporativa y Hardening de Active Directory

Resumen Ejecutivo: Implementación de una infraestructura de dominio empresarial con réplica y sincronización hacia Microsoft Entra ID (Azure AD). Se estructuraron Unidades Organizativas bajo el principio de menor privilegio (PoLP), asignación de directivas de grupo para mitigación de movimientos laterales y políticas de contraseñas robustas.

Arquitectura: Bosque AD DS + Sync Cloud
Políticas Aplicadas: +35 GPOs de Seguridad CIS
Gobernanza: RBAC y Control de Acceso
Ver Detalles de Ingeniería y Troubleshooting Técnico
1. Topología y Desafío de Red

Se desplegaron 2 Domain Controllers (DC01 primario y DC02 en réplica) en subredes aisladas. Se solventaron problemas de resolución DNS inversa y sincronización de catálogos globales tras la replicación forzada con ntdsutil y repadmin.

# Verificación de integridad de replicación y KDC
repadmin /showrepl * /csv > repl_status.csv
dcdiag /v /c /d /e /test:sysvolcheck
2. Hardening Aplicado

Deshabilitación completa de protocolos obsoletos NTLMv1 y SMBv1 mediante directivas centrales. Restricción de permisos sobre el atributo AdminSDHolder y segmentación de cuentas administrativas mediante modelo de Tiering (Tier 0 para DCs, Tier 1 para servidores de aplicación, Tier 2 para endpoints).

Despliegue de Plataforma SIEM/EDR y Análisis de Telemetría con Wazuh y Splunk

Configuración de reglas personalizadas para detección temprana de ataques de fuerza bruta, ejecución sospechosa de procesos y cambios no autorizados en archivos críticos.

Ingesta de Eventos: WinEventLog + Sysmon + Auditd
Tiempo de Detección: < 3 Segundos (Alertas en vivo)
Mapeo Defensivo: Tácticas MITRE ATT&CK

1. Canalización de Registros y Sysmon

Instalación de agentes Wazuh coordinados con SwiftOnSecurity Sysmon config en Windows para capturar creación de procesos anómalos (EventID 1) y conexiones de red no estándar (EventID 3). Los logs se enviaron mediante forwarders seguros SSL/TLS al clúster de indexación.

2. Simulación de Amenazas y Verificación

Se ejecutaron simulaciones controladas de spraying de contraseñas y evasión mediante PowerShell ofuscado. El SIEM generó la alerta correlacionada correspondiente y ejecutó un script de respuesta activa (Active Response) aislando la IP origen en el firewall del host.

Infraestructura de Servidores Proxmox VE con Contenedores Docker Seguros

1. Red Privada Virtualizada y Bridging

Configuración de bridges internos en Proxmox (vmbr0, vmbr1) separando la red de administración de la red DMZ. Creación de reglas estrictas en el firewall del hipervisor para rechazar tráfico ICMP no deseado y bloquear intentos de conexión SSH repetidos vía fail2ban.

cap_drop:
  - ALL
read_only: true
